Anran Jiao 个人网站

本压缩包包含最新版主页、Curriculum Vitae、Beyond Research，以及对应的图片、字体和交互脚本。

发布到 GitHub Pages

将解压后的文件放到 anranjiao/anranjiao.github.io 仓库根目录，使 index.html 位于根目录。GitHub Pages 的发布目录也应指向这里。保留随附的 .nojekyll 文件。

GitHub 官方说明
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

本地预览

在解压后的目录中运行以下命令，然后在浏览器打开 http://localhost:8000

python3 -m http.server 8000

页面位置

主页为 index.html，CV 为 cv/index.html，Beyond 为 beyond/index.html。图片、字体和脚本位于 assets 文件夹。修改网页内容后保存对应的 HTML 文件即可。
